Q9. What is the main difference between a static website and a dynamic website?

A static website displays fixed, pre-built content identical for every user, whereas a dynamic website generates or updates content in real time based on user interactions, database queries, or server responses.


Q10. Name the three pillars of Front-end Web Development and write one line about each.

HTML (HyperText Markup Language): Provides the foundational structure and semantic layout of the webpage.
CSS (Cascading Style Sheets): Controls visual presentation, styling, layout, and responsiveness.
JavaScript: Implements dynamic behavior, user interactivity, and complex web logic.


Q11. What is the difference between Frontend and Backend?

The Frontend (client-side) represents everything users see on the screen the UI, while the Backend (server-side) handles background operations which we can't see on the screen like database management, and API.


Q12. What is Node.js?
Node.js is an open-source, runtime environment that is used to run JavaScript code in our local system. For example the environment built on Google Chrome's V8 engine that allows developers to run JavaScript outside the browser.
